Raw results:

Key deltas:
- `BenchmarkViewLogs10000Plain`

  - after: ~0.206 ms/op
  - result: ~143x faster
- `BenchmarkLogKeyScrollView10000Plain`
  - before: ~29.4 ms/op
  - after: ~0.202 ms/op
  - result: ~145x faster
- `BenchmarkHandleLogsResultAppend200Into10000`
  - before: ~0.69 ms/op
  - after: ~0.55-0.57 ms/op
  - result: ~18% faster

Notes:
- `BenchmarkRenderLogs*` now measures steady-state cached render path, so direct before/after ns/op there is not an apples-to-apples cold-render comparison.
- Main user-visible win is scroll/view latency because logs body rendering is cached and viewport content is no longer reset when unchanged.
- Multi-source fetch is now parallelized with bounded concurrency, but that gain is not represented by these microbenches because they do not hit live clusters.
